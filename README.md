如果你符合下面任意几条，这套内容就很适合你：

- 会一点 Python，但刚系统接触 PyTorch
- 不想只看 Notebook 演示，想在本机真正把代码跑起来
- 想理解训练、评估、推理、保存、续训、部署之间的关系
- 希望以后做新任务时，有一套可以复用的本地项目骨架

## 学完这套教程，你应该能做到什么

如果你把这 15 篇真正按顺序走完，并且愿意自己动手改代码，最终你应该具备下面这些能力：

- 能独立搭一个本地 PyTorch 学习/实验环境
- 能理解 Tensor、autograd、`nn.Module`、DataLoader 的核心角色
- 能写出一个完整训练循环，并看懂 loss、梯度、参数更新的关系
- 能完成一个基础图像分类任务，并用验证集判断模型是否靠谱
- 能保存模型、恢复 checkpoint、写本地推理脚本
- 能处理 GPU / AMP、常见报错与调试
- 能整理出一个可复用的小型训练模板，而不是每次重头拼脚本

换句话说，这套教程的目标不是让你"会几个 PyTorch API"，而是让你：

> **从入门示例，走到一个像样的小项目闭环。**

## 这套内容最适合怎么学

我建议不要只"顺着看"，最好按下面方式学：

### 1. 每篇先看理论，再亲手跑代码

不要只浏览代码块。PyTorch 很多内容只有你真正运行、打印 shape、改一改参数后才会变成自己的理解。

### 2. 每篇至少做 1~2 个练习

只看不改，容易停留在"眼熟"。

### 3. 遇到报错先自己归类

优先先问自己：

- 是 shape 问题？
- 是 dtype 问题？
- 是 device 问题？
- 是模型结构与权重不一致？

这样学得会更扎实。

### 4. 学到后半段时，开始把代码往 `project_demo` 收

这样你最终会得到一套真正可复用的本地模板，而不只是零散示例。

### 5. 不要把这套教程当成"读完就结束"

真正有价值的是：

- 跑通
- 改动
- 排错
- 复用

只要你把这四步都做过，这套内容才会从"看过"变成"掌握过"。
